# Embudo de Captación Infalible

Embudo de captación multiidioma para asesoría independiente en ahorro de
servicios del hogar: seguros (médico, dental, coche), luz, internet,
TV, móvil e hipoteca. Capta clientes interesados en ahorrar y también
personas que quieran unirse al equipo.

**Funcionalidades:** formulario por pasos, cálculo del gasto anual,
validación de datos, consentimiento RGPD, ventana emergente para
captación de equipo y guardado en base de datos.

**Tecnologías:** Python, Streamlit, SQLite
